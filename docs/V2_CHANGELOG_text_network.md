* "A. My E. H. Ood" (MSFT CFO) and "M. Arc D. H. Amburg" (BRK-B) space-split names are not repaired; the network agent's letters-only comparison keeps them from being false changes.

* WorldCom FY1997 (+1876%) remains: FY1996 and FY1997 are both inline Item 13, so it is a like-for-like comparison.
