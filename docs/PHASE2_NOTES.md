Cross-cutting facts the pipeline/evaluator/app owners MUST honour:
1. State keys to ADD to agents/state.py: `annual_facts` (AnnualFacts built once in fetch_data via tools.xbrl_parser.get_annual_facts incl. one baseline year before the first analysis year, point-in-time as_of), `focus_year`, `grade_rationale: str`, plus anything else agents return (jev_available, agent_severity, smoking_gun_evidence ...). 2. Agents expect `filing_texts`/`filing_metadata` to include ONE BASELINE YEAR before the first analysis year (YoY baseline; network agent compares first analysed year with it; language agent uses extra years as baseline only).
3. statement_parser needs RAW HTML/text (tools.edgar_api.fetch_filing_html), never fetch_filing_text output (silently wrong numbers). get_annual_facts already does this.
4. Audit fees: only from proxy DEF 14A text before FY2003 / when Item 14 incorporates by reference: fetch DEF 14A filed <= as_of and pass proxy_text to text_parser.build_filing_metadata.
5. 10-K/A are excluded everywhere (no restatement visibility from amendments filed before as_of is a known gap; document, don't hide).
6. `risk_grade` may be "Unknown" (synthesis internal failure): UI/evaluator/watchlist must treat it as an error state, not Low. `risk_changed` from synthesis is true for improvements too; watchlist alerting is worsened-only (watchlist/scheduler.should_alert).
7. Peer agent: flags are two-sided and carry `direction`; Apple (clean) gets 2 favourable-direction outliers (receivables-vs-revenue growth z=-5.6, ROA z=+2.6) -> Medium severity. Peer finder uses prior-year peer data when the peer hasn't filed the focus year by as_of, widens size band once, adds 2-digit SIC tier; cold discovery 30-45 s, cached 0 s. Pre-2009 / non-USD companies -> no peers (explicit unavailable).
8. Language agent: passive-voice flag fires on ~100% of filings at the spec threshold (see TUNING_LEDGER P2: pre-registered `no_passive` variant must be supported by the pipeline/evaluator via a config switch `EXCLUDE_FLAGS` applied consistently in agent severity, temporal scoring and synthesis, WITHOUT changing the headline default). Specificity score needs ANTHROPIC_API_KEY (else unavailable + degraded).
