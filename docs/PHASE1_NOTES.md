## Builder: metrics

**files**: C:\Users\Utsav.Sharma\source\forensic-filing-agent\tools\financial_metrics.py, C:\Users\Utsav.Sharma\source\forensic-filing-agent\tests\test_financial_metrics.py

**api**: All functions take flattened year dicts {canonical: float|None}; FactValue dicts ({"value":..}) are also accepted. Every function returns a dict with status (ok|unavailable|not_meaningful), missing (sorted canonical names), missing_xbrl_hints, explanation. They never raise and never emit NaN/inf (non-finite becomes None; the tests check this with json.dumps(allow_nan=False)).

Constants: CANONICAL_TO_XBRL_HINT, BENEISH_COEFFS, BENEISH_INTERCEPT(-4.84), BENEISH_SAMPLE_MEANS, BENEISH_HIGH_CUTOFF(-1.78), BENEISH_LOW_CUTOFF(-2.22).

Functions:
- classify_beneish(m) -> {zone: manipulator|grey|unlikely, flag_level: HIGH|MEDIUM|LOW, flag: bool}. M>-1.78 is manipulator, M<-2.22 is unlikely, and exactly -1.78 or -2.22 is grey.
- classify_altman(score, variant="Z"|"Z-prime"|"Z-double-prime") -> "distress"|"grey"|"safe". Cut-offs 1.81/2.99, 1.23/2.90, 1.10/2.60; the boundaries are grey.
- beneish_m_from_components(components) -> float|None
- beneish_m_score(cur, prev, impute_neutral=("SGAI","DEPI")) -> {status, m_score, components{DSRI,GMI,AQI,SGI,DEPI,SGAI,TATA,LVGI}, imputed, imputed_reasons, zone, flag_level, flag, missing, missing_detail{cur,prev}, undefined{comp:reason}, inputs{cur,prev}, explanation, missing_xbrl_hints}. Only SGAI and DEPI can be imputed, with neutral 1.0, and each imputation is always reported. Any other gap or zero denominator gives status unavailable and m_score None.
- beneish_explanation_facts(components, cur, prev) -> {revenue_growth_pct, receivables_growth_pct, gross_margin_cur, gross_margin_prev, gross_margin_change_pp, sga_pct_revenue_change_pp, accrual_amount, accrual_to_assets, accrual_pct_of_net_income, asset_quality_cur/prev, leverage_cur/prev, components, contributions (coef*(v-1), or coef*TATA, sorted descending), top_drivers (up to 3)}
- altman_z(cur, market_cap=None) -> {status, score, zone, variant: "Z" if market_cap>0 else "Z-prime", components{X1..X5}, derived[], missing, explanation}. EBIT falls back to NI+IncomeTaxExpense+InterestExpense when OperatingIncome is missing. TotalLiabilities falls back to TotalAssets-StockholdersEquity. Both fallbacks are listed in `derived`.
- altman_z_double_prime(cur) -> same shape, variant "Z-double-prime". Uses no sales term and no +3.25 constant.
- revenue_quality(cur, prev=None) -> {status, ratio, prior_ratio, low, prior_low, consecutive_low, flag, flag_evaluable, ...}. The flag needs both years below 0.8. NI<=0 gives not_meaningful. If the prior year is missing, the ratio is still returned with flag=False and flag_evaluable=False.
- dso(cur, prev=None) -> {status, dso_days, prior_dso_days, yoy_change_pct, flag}. Flag is YoY > +20%, strictly greater.
- accruals_ratio(cur) -> {status, ratio, accrual_amount, flag}. Ratio is (NI-OCF)/TA; flag is > 0.05.
- gross_margin(cur), ocf_to_revenue(cur), roa(cur) -> {status, value, ...}
- debt_to_equity(cur) -> {status, value, partial}. (LTD+CurrentDebt)/Equity. If CurrentDebt is absent it uses LTD only, sets partial=True and lists CurrentDebt in missing. Equity<=0 gives not_meaningful.
- receivables_vs_revenue_growth(cur, prev) -> {status, revenue_growth, receivables_growth, difference, ratio}. Values are fractions, not percent; ratio equals DSRI.

**gaps**: - Beneish (1999) Table means could NOT be verified from the primary paper (paywalled; several fetches returned 403 or no table). The numbers come from a secondary source, Siregar et al. 2023, J. Systems & Management Sciences 13(6), whose 'parameter index' table lists DSRI 1.031/1.465, GMI 1.014/1.193, AQI 1.039/1.254, SGI 1.134/1.607, DEPI 1.001/1.077, LVGI 1.037/1.111, TATA 0.018/0.031 and SGAI manipulator 1.041. The same source lists the SGAI non-manipulator value as 1.001, which looks garbled; I used 1.054 from my own recollection, so that single entry is not independently verified. Its effect on M is only 0.172*0.05 = 0.009, and the asserted M bands are wide enough to cover either value.
- The -2.22 grey-zone lower cut-off is a SPEC parameter. Secondary sources attribute -2.22 to the original paper, but other sources describe it inconsistently. I did not re-derive it.
- The 8-variable coefficients, TATA = (NI-OCF)/TA, DEPI, SGAI and LVGI definitions were confirmed against Wikipedia and several secondary sources. The Z' and Z'' coefficients and zones were confirmed against a secondary tabulation. The Altman Z (1968) coefficients are the SPEC's rounded form 1.2/1.4/3.3/0.6/1.0; the paper prints 0.999 for sales. Z'' is without the +3.25 constant. The original Altman and Beneish papers were not accessible.
- AQI omits Beneish's 'securities' term (no canonical item), as the SPEC states. LVGI requires LongTermDebt and treats it as non-imputable. Filers with no long-term debt tag will therefore get Beneish 'unavailable' unless the parser supplies 0 for LongTermDebt or Beneish is rerun with a different policy. Imputing 0 would be inventing a number, so I did not do it.
- Negative Depreciation is treated as undefined, so DEPI is imputed neutral and reported.
- Negative or zero-margin cases (such as negative gross margin) still compute mathematically. There is no sector-specific logic (Beneish/Altman are for non-financial firms).
- Test fixtures are synthetic arithmetic inputs, not EDGAR-fetched data, so there are no real-company tests. Beneish on Enron 2000 or Luckin 2019 was not run here. It needs the xbrl_parser and statement_parser output.
